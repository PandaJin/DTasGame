# PRD: QuarterPlan 导航重构与活动圆环日历

## 1. 背景与动机

### 现状问题
当前 QuarterPlan 的导航结构为：**概览 → 季度 → 时间追踪 → 数据分析 → 设置**

存在以下问题：
1. **概览页价值低**：只起到跳转中转站的作用——"管理季度"跳到季度页，"查看详情"跳到追踪页，自身不提供独特信息
2. **信息架构不符合心智模型**：用户日常使用最多的是"记录今天做了什么"，但这个操作藏在第三个 tab
3. **缺乏时间维度的层次感**：没有"本周"视角来回顾和补录，也无法直观看到季度中每一天的投入情况
4. **数据分析页面孤立**：分析内容与季度详情分离，用户需要在两个页面间切换对照

### 目标
重构为以**时间粒度递进**为核心的导航：**本日 → 本周 → 季度 → 设置**，让用户在每个维度都能获得完整的信息闭环。

---

## 2. 用户画像

- 知识工作者 / 自由职业者 / 学生
- 以季度为周期制定目标，拆解为多个任务
- 每天需要记录在各任务上的时间投入
- 希望快速了解"今天做得怎么样""这周进度如何""季度整体是否 on track"

---

## 3. 功能需求

### 3.1 导航重构

**新导航栏（4 项）**：

| 顺序 | 名称 | 路由 | 图标 | 说明 |
|------|------|------|------|------|
| 1 | 本日 | `/dashboard/today` | Sun | 今日计时 + 记录（原追踪页） |
| 2 | 本周 | `/dashboard/week` | CalendarDays | 本周 7 天视图 + 补打卡 |
| 3 | 季度 | `/dashboard/quarters` | Calendar | 季度管理 + 圆环日历 + 数据分析 |
| 4 | 设置 | `/dashboard/settings` | Settings | 用户设置 |

**路由变更**：
- `/dashboard` → 自动重定向到 `/dashboard/today`
- `/dashboard/track` → 迁移到 `/dashboard/today`
- `/dashboard/analytics` → 删除，内容合并到季度详情页
- 登录后默认跳转 `/dashboard/today`

---

### 3.2 本日页

**路由**：`/dashboard/today`

**定位**：用户每天打开 APP 的第一个页面，聚焦"现在要做什么"和"今天做了什么"。

**内容结构**：
```
┌─────────────────────────────────────┐
│ 今日                  [+ 手动添加]  │
│ 2026年2月17日 星期二                │
├─────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐          │
│ │ 今日投入  │ │ 本周投入  │          │
│ │ 2h 30m   │ │ 12h 15m  │          │
│ └──────────┘ └──────────┘          │
├─────────────────────────────────────┤
│ 选择任务开始计时                     │
│ ● 任务A          P1  ▶             │
│ ● 任务B          P2  ▶             │
│ ● 任务C          P3  ▶             │
├─────────────────────────────────────┤
│ 今日记录                总计: 2h30m │
│ ● 任务A  1h30m  🕐                 │
│ ● 任务B  1h00m  ⏱                 │
└─────────────────────────────────────┘
```

**功能点**：
- 计时器（一键点击任务开始计时，已实现的紧凑 UI）
- 今日统计卡片（今日投入 + 本周投入）
- 今日时间记录列表（可删除）
- 手动添加时间记录按钮

### 3.3 本周页

**路由**：`/dashboard/week`

**定位**：回顾本周每一天的进展，补录遗漏的时间记录。

**内容结构**：
```
┌─────────────────────────────────────┐
│ 2月16日 - 2月22日     [<] [本周] [>]│
├─────────────────────────────────────┤
│ 本周汇总: 12.5h / 目标 20h    63%  │
│ ██████████████░░░░░░░░              │
├─────────────────────────────────────┤
│ ┌─ 周一 2/17 ─────────── 3.5h ──┐  │
│ │ ████████████░░ 88% (目标4h)    │  │
│ │ ● 任务A          1.5h         │  │
│ │ ● 任务B          2.0h         │  │
│ │                   [+ 补打卡]   │  │
│ └────────────────────────────────┘  │
│ ┌─ 周二 2/18 ─────────── 4.0h ──┐  │
│ │ ████████████████ 100% (目标4h) │  │
│ │ ● 任务A          2.0h         │  │
│ │ ● 任务C          2.0h         │  │
│ │                   [+ 补打卡]   │  │
│ └────────────────────────────────┘  │
│ ...（7天）                          │
└─────────────────────────────────────┘
```

**功能点**：
- **周汇总**：本周总投入 vs 每周目标，进度条
- **7 天卡片**：每天一张卡片，显示：
  - 日期 + 星期 + 当日总时长
  - 每日目标进度条（当日投入 / 每日目标）
  - 各任务的投入明细（颜色圆点 + 任务名 + 时长）
  - "补打卡"按钮（打开预填日期的手动添加对话框）
- **周导航**：可以通过前后箭头浏览历史周
- 今天的卡片视觉高亮

### 3.5 活动圆环（Apple Fitness 风格）

**定位**：以直觉化的视觉方式展示每一天的"健康度"，三个维度各用一个圆环。

#### 三环定义

| 圆环 | 位置 | 颜色 | 含义 | 满值定义 |
|------|------|------|------|----------|
| 外环 | 最外 | #FA114F (红/粉) | 高优先级完成度 | P1+P2 任务的每日目标时间（P1+P2 每周目标 ÷ 5） |
| 中环 | 中间 | #92E82A (绿) | 每日总完成度 | 全部任务的每日目标时间（总每周目标 ÷ 5） |
| 内环 | 最内 | #00C7E6 (青) | 绝对工作时长 | 固定 8 小时 |

#### 视觉规格

- **日历中的小圆环**：36×36px，stroke-width 3px
- **详情对话框中的大圆环**：120×120px，stroke-width 12px
- 背景环：对应颜色 20% 不透明度
- 进度环：圆角端头（strokeLinecap round），从 12 点钟方向顺时针
- 超过 100% 时 cap 在满圆（v1 不做超额动画）

#### 日详情对话框

点击日历中某天的圆环，弹出对话框：

```
┌──────────────────────────┐
│     2月17日 星期二         │
│                          │
│       (大号三环图)         │
│                          │
│ 🔴 高优先级  1.5h / 2.4h │
│ 🟢 每日目标  3.5h / 4.0h │
│ 🔵 工作时长  3.5h / 8.0h │
│                          │
│ 时间分配                  │
│ ● 任务A (P1)     1.5h   │
│ ● 任务B (P2)     1.0h   │
│ ● 任务C (P3)     1.0h   │
└──────────────────────────┘
```

## 4. 非功能需求

- **性能**：圆环使用纯 SVG 实现，不引入额外图表库。季度日历的数据预计算（90天 × 数百条记录）在服务端完成。
- **响应式**：
  - 日历：桌面端 3 月横排，移动端纵向堆叠
  - 本周页：桌面端 7 天可并排或列表，移动端纵向卡片
- **无障碍**：圆环添加 aria-label 描述进度值
- **国际化**：保持中文界面，日期使用 zhCN locale
