# PRD: CyclePlan v2 — 任务独立化 + 周期化重构

## 1. 背景与动机

### 从 QuarterPlan 到 CyclePlan

v1（QuarterPlan）的核心假设是"任务从属于季度"。但实际使用中发现：

1. **任务跨季度延续是常态**：很多任务（如"学英语""健身"）持续数个季度，每次新建季度都要重新创建
2. **"季度"太固定**：有些人按月规划，有些按 6 周冲刺，硬编码"季度"概念不够灵活
3. **任务作为一级实体更符合心智模型**：用户首先关心的是"我有哪些任务"，而不是"我有哪些季度"
4. **计时入口藏得太深**：计时功能在独立的"今日"页面，不够便捷

### 目标

- 任务独立于周期，可跨周期复用
- "周期"替代"季度"，支持任意时间跨度
- 任务成为第一入口，导航以任务为中心
- 计时入口随处可达（TikTok 风格底部"+"按钮）

---

## 2. 数据模型

### v1 模型
```
User → Quarter → Task → TimeEntry
```
Task 硬绑定到 Quarter（quarter_id FK + CASCADE）。

### v2 模型
```
User → Task（独立实体）
User → Cycle（时间周期）
Cycle ←→ Task via cycle_tasks（多对多关联）
Task → TimeEntry
```

### 关键变更

| 变更 | 说明 |
|------|------|
| `quarters` → `cycles` | 表重命名 |
| `tasks.quarter_id` | 从 NOT NULL 变为可选 |
| `tasks.user_id` | 新增，直接关联用户 |
| `cycle_tasks` | 新建多对多关联表，含 `weekly_target_hours` |

## 3. 导航结构

### 底部导航（5 项，中间为"+"计时按钮）

```
┌─────────────────────────────────────┐
│  任务    本周    [+]    周期    我的  │
└─────────────────────────────────────┘
```

| 位置 | 名称 | 路由 | 图标 | 说明 |
|------|------|------|------|------|
| 1 | 任务 | `/dashboard/tasks` | ListTodo | 所有任务管理（第一入口） |
| 2 | 本周 | `/dashboard/week` | CalendarDays | 本周 7 天视图 |
| 中 | + | — | Plus/Timer | 计时入口（弹出面板） |
| 3 | 周期 | `/dashboard/cycles` | Calendar | 周期列表+详情 |
| 4 | 我的 | `/dashboard/me` | User | 设置+周期管理 |

### "+"按钮行为

- **未计时**：弹出底部面板，显示任务列表，点击任务一键开始计时
- **计时中**：按钮变为脉冲动画 + 已计时时长，点击弹出计时控制面板（暂停/停止）
- **停止时**：弹出备注对话框，保存后显示 toast "记录已保存"

## 4. 页面设计

### 4.1 任务页 (`/dashboard/tasks`)

所有任务的管理中心，支持筛选（进行中/已归档）。

每个任务卡片显示：
- 颜色标识 + 任务名 + 优先级
- 总进度条（已投入/预估）
- 本周投入时长
- 点击进入任务详情

### 4.2 任务详情页 (`/dashboard/tasks/[id]`)

- 进度概览（进度条 + 已投入/预估时间）
- 所属周期列表
- 近 30 天每日投入柱形图
- 时间记录列表（可展开查看详情）

### 4.3 本周页 (`/dashboard/week`)

- 周汇总：总投入 vs 目标
- **周小结**（新增）：按任务聚合本周投入 vs 目标
- 7 天紧凑卡片：每天显示任务分布 + "+"补录按钮
- 支持周导航

### 4.4 周期页 (`/dashboard/cycles`)

- 周期列表：活跃高亮，显示剩余天数和任务数
- 周期详情：进度条（时间+任务）、活动日历（三环）、任务列表、数据分析
- 支持"从已有任务添加到此周期"

### 4.5 我的页 (`/dashboard/me`)

合并原"设置"页面 + 周期管理：
- 个人信息设置
- 周期列表管理（创建/设为活跃/删除）
- 退出登录

## 5. UI 优化

| 优化项 | 说明 |
|--------|------|
| 手机端紧凑布局 | 减少 padding 和卡片间距 |
| 时间记录可展开 | 点击展开显示开始/结束时间、备注、类型 |
| 每周趋势柱形图 | Line→Bar 更直观 |
| 删除对齐分数 | 简化优先级分析 |
| Toast 通知 | 计时保存后 toast 提示 |

## 6. 路由映射

| v1 路由 | v2 路由 | 动作 |
|---------|---------|------|
| `/dashboard` | `/dashboard` | redirect → `/dashboard/tasks` |
| `/dashboard/today` | 删除 | 计时移到"+"面板 |
| `/dashboard/week` | `/dashboard/week` | 保留+增强 |
| `/dashboard/quarters` | `/dashboard/cycles` | 重命名 |
| `/dashboard/quarters/[id]` | `/dashboard/cycles/[id]` | 重命名+优化 |
| `/dashboard/settings` | `/dashboard/me` | 合并 |
| — | `/dashboard/tasks` | 新建（第一入口） |
| — | `/dashboard/tasks/[id]` | 新建 |
