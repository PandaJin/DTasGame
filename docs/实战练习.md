### 🎯 目标

```bash

```

内容：
```sql
-- 添加完成状态字段
ALTER TABLE public.tasks 
ADD COLUMN is_completed BOOLEAN DEFAULT false;

-- 添加完成时间字段
ALTER TABLE public.tasks 
ADD COLUMN completed_at TIMESTAMPTZ;

-- 添加索引
CREATE INDEX idx_tasks_completed ON public.tasks(is_completed);
```

#### 2. 在Supabase执行迁移
1. 登录 https://supabase.com/dashboard
2. 选择你的项目

5. 刷新Table Editor，看到新字段

#### 3. 更新TypeScript类型
打开 `src/types/database.ts`，找到Task接口：
```typescript

  id: string
  quarter_id: string
  name: string

  color: string
```

#### 4. 添加完成按钮
修改 `src/app/dashboard/page.tsx`，在任务卡片中添加：
```typescript
<Button
  size="sm"
  variant={task.is_completed ? "secondary" : "default"}
  onClick={async () => {
    await supabase
      .from('tasks')
      .update({ 
        is_completed: !task.is_completed,
        completed_at: !task.is_completed ? new Date().toISOString() : null
      })
      .eq('id', task.id)
    
    // 刷新页面
    window.location.reload()
  }}
>
  {task.is_completed ? '✅ 已完成' : '⭕ 标记完成'}
</Button>
```

#### 2. 编写组件代码
```typescript
// src/components/dashboard/stats-card.tsx
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'

interface StatsCardProps {
  title: string
  value: string | number
  description?: string
  icon?: React.ReactNode
}

export function StatsCard({ title, value, description, icon }: StatsCardProps) {
  return (
    <Card>
      <CardHeader className="flex flex-row items-center justify-between pb-2">
        <CardTitle className="text-sm font-medium">{title}</CardTitle>

      </CardHeader>
      <CardContent>
        <div className="text-2xl font-bold">{value}</div>
        {description && (

        )}
      </CardContent>
    </Card>
  )
}
```

## 🚀 任务五：实现简单的搜索功能

### 🎯 目标
添加客户端交互，理解状态管理

### 📋 步骤

#### 1. 在季度页面添加搜索框
修改 `src/app/dashboard/quarters/page.tsx`：
```typescript
'use client'  // ⚠️ 需要改为Client Component

import { useState } from 'react'
import { Input } from '@/components/ui/input'
import { Search } from 'lucide-react'

export default function QuartersPage() {
  const [searchTerm, setSearchTerm] = useState('')
  
  // 获取数据的代码...（需要改用useQuery）
  
  // 过滤任务
  const filteredTasks = tasks?.filter(task => 
    task.name.toLowerCase().includes(searchTerm.toLowerCase())
  )
  
  return (
    <div>
      {/* 搜索框 */}
      <div className="relative mb-6">
        <Search className="absolute left-3 top-3 h-4 w-4 text-muted-foreground" />
        <Input
          placeholder="搜索任务..."
          value={searchTerm}
          onChange={(e) => setSearchTerm(e.target.value)}
          className="pl-10"
        />
      </div>
      
      {/* 显示过滤后的任务 */}
      <div className="grid gap-4">
        {filteredTasks?.map(task => (
          <TaskCard key={task.id} task={task} />
        ))}
      </div>
      
      {/* 无结果提示 */}
      {searchTerm && filteredTasks?.length === 0 && (
        <div className="text-center py-12 text-muted-foreground">
          未找到匹配的任务
        </div>
      )}
    </div>
  )
}
```

#### 2. 优化：添加防抖
安装lodash（可选）：
```bash
npm install lodash
npm install @types/lodash --save-dev
```

使用防抖优化：
```typescript
import { useMemo, useState } from 'react'
import { debounce } from 'lodash'

const [searchTerm, setSearchTerm] = useState('')
const [debouncedSearch, setDebouncedSearch] = useState('')

// 创建防抖函数
const debouncedSetSearch = useMemo(
  () => debounce((value: string) => {
    setDebouncedSearch(value)
  }, 300),
  []
)

// 输入框onChange
onChange={(e) => {
  setSearchTerm(e.target.value)  // 立即更新输入框
  debouncedSetSearch(e.target.value)  // 300ms后更新搜索
}}

// 使用debouncedSearch过滤
const filteredTasks = tasks?.filter(task => 
  task.name.toLowerCase().includes(debouncedSearch.toLowerCase())
)
```

### ✅ 验证
- [ ] 输入框正常显示
- [ ] 输入文字立即过滤任务
- [ ] 清空搜索显示所有任务
- [ ] 无结果时显示提示
- [ ] （如添加防抖）输入停止300ms后才过滤

### 💡 知识点
- **Client Component**：需要使用useState的组件必须是客户端组件
- **受控组件**：`value` + `onChange` 完全控制输入框
- **数组过滤**：使用`filter` + `includes`实现搜索
- **防抖(Debounce)**：避免频繁操作，提升性能
- **条件渲染**：`&&` 短路运算实现条件显示

**性能思考**：
- 如果有1000个任务，搜索会卡顿吗？
- 如何优化？（虚拟列表、服务器端搜索）
- 何时应该用客户端搜索 vs 服务器端搜索？
